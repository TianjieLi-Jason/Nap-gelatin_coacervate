# Nap-gelatin_coacervate
## [Input files](./input)
- `martini_v3.0.0_0.90.itp`: tuned MARTINI3 parameters used in this work.
- `topol_gel.itp`: CG topology of non-grafted native gelatin.
- `topol_nap.itp`: CG topology of triple-Nap-grafted gelatin.
- `topol_nap_double_x.itp`: CG topologies of double-Nap-grafted gelatin.
- `topol_nap_single_x.itp`: CG topologies of single-Nap-grafted gelatin.
- `topol_free_nap_x.itp`: CG topologies of free Nap.
## [MD simulations of Gel](./Gel)
- `Gel-initial.gro`: initial structure file of Gel. (after energy minimization and equilibrations)
- `Gel-5us-runi.gro`: final structure file of Gel from the ith replica at 5μs.
